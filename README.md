# Mars-Lander-2
Implementação em Python para o desafio Mars Lander 2 (CodinGame). O algoritmo utiliza controle vetorial e física cinemática para guiar uma sonda até o pouso em terreno acidentado. Gerencia inclinação e empuxo para respeitar limites de velocidade ($V_v \le 40, V_h \le 20$) e otimizar o consumo de combustível através de transições de estado.
